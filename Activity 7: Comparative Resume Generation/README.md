Activity 7: Comparative Resume Generation Using Multiple LLMs

Activity Description

This activity focused on exploring how different large language models (LLMs) can generate professional resumes using the same personal information and instructions. I used ChatGPT and Gemini to create resume drafts and compare their outputs.

The activity involved examining how each AI tool organized information, presented qualifications, and designed the resume content. I also evaluated the strengths and weaknesses of each output to determine which version was more appropriate and how it could be improved.

What Have I Learned?

Through this activity, I learned how AI tools can assist in creating professional documents, particularly resumes. I also developed my ability to compare AI-generated content, identify errors or missing information, and evaluate which output best meets a specific purpose.

One challenge I encountered was determining which resume version presented the information most clearly and professionally. I addressed this by comparing the outputs based on organization, accuracy, readability, and relevance.

In the future, I can apply these skills when preparing professional documents, improving my resume, and using AI responsibly for academic and career-related tasks.
