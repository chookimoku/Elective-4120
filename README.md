## 📚 Laboratory Projects

Here are the seven laboratory activities I completed:

### 🎨 Activity 1: Presentation Design Principles

An activity focused on applying basic design principles to create effective, organized, and visually appealing presentations and promotional materials.

### 🌷 Activity 2: Color Palette and Typography

An activity about developing a personal branding kit by selecting appropriate colors, fonts, and visual elements to create a consistent and attractive identity.

### 💧 Activity 3: Social Media Infographics and Mini Project Documentation

An activity focused on creating an infographic about water scarcity and proposing a technology-based solution through project documentation.

### 💻 Activity 4: Group Reporting about Google Apps

A collaborative activity in which the class was divided into five groups, with each group assigned a different Google application to research and present. Our group discussed **Google Forms and Google Meet**.

### 🤖 Activity 5: Exploring and Improving AI Prompts

An activity that explored AI image generation using Gemini by creating an original prompt and improving it to produce more detailed and specific results.

### 🐾 Activity 6: Replit Implementation

An activity focused on using Replit AI to develop a one-page website based on a business idea. My chosen concept was **Paws & Whiskers Pet Shop**.

### 📄 Activity 7: Comparative Resume Generation Using Multiple LLMs

An activity that involved using ChatGPT and Gemini to generate, compare, and evaluate AI-generated professional resumes.
